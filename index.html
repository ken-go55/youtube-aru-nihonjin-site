youtube-aru-nihonjin 週報

YouTubeチャンネル「ある日本人の一生」「Simulated Lives of Japan」の運営者が、自分のチャンネルの数字を振り返るための個人用ツールです。
A private tool the owner of the YouTube channels "ある日本人の一生" and "Simulated Lives of Japan" uses to review their own channel statistics.

このツールについてAbout

運営者の自宅サーバーで週に1回動き、運営者自身のチャンネルの数字とコメントを読み取って、運営者向けの週報を作ります。一般の方が使うものではなく、運営者以外のGoogleアカウントでは使いません。

It runs once a week on the owner's home server, reads statistics and comments of the owner's own channels, and produces a weekly report for the owner. It is not offered to the public and is used only with the owner's Google account.

プライバシーポリシーPrivacy policy

読み取るもの：YouTube Data API と YouTube Analytics API を通じて、運営者のチャンネルの動画一覧、再生数・高評価数・コメント数、視聴時間・平均視聴率・視聴維持率・流入元、登録者数、動画に付いたコメントの本文・高評価数・日時。許可の範囲は読み取りだけ（youtube.readonly・yt-analytics.readonly）で、投稿・返信・設定の変更は行いません。

What is read: via the YouTube Data API and YouTube Analytics API, the owner's channel video list, views, likes, comment counts, watch time, average view percentage, audience retention, traffic sources, subscriber count, and comment text, like counts and dates. Only read-only scopes are requested; the tool never posts, replies or changes settings.

使い道：運営者が動画の内容や構成を見直すための週報づくりにだけ使います。広告、販売、第三者への提供には使いません。

Use: only to produce the owner's weekly review report. The data is not used for advertising, not sold, and not shared with third parties.

コメントの扱い：コメントを書いた人の名前やアカウントの情報は保存しません。週報にはコメントの本文の一部だけを載せます。

Comments: commenters' names and account details are not stored. The report quotes only parts of the comment text.

保存する場所と期間：集めた数字は運営者の自宅サーバーに保存し、チャンネルの運営を続ける間だけ持ちます。認証情報はサーバーの中だけに置き、外部に送りません。

Storage: collected data is kept on the owner's home server for as long as the channels are operated. Credentials stay on that server and are never sent elsewhere.

許可の取り消し：Googleアカウントの「セキュリティ → サードパーティ製のアプリとサービス」から、いつでも取り消せます。取り消すと、このツールは数字を読み取れなくなります。

Revoking access: access can be revoked at any time from Google Account → Security → Third-party apps and services.

このツールによるYouTube APIの利用は、YouTube利用規約とGoogleプライバシーポリシーに従います。

Use of the YouTube API Services follows the YouTube Terms of Service and the Google Privacy Policy.
